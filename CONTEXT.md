# Stores4u

Stores4u is a single-store retail system used by dashboard staff to manage store operations.

## Language

**User Language Preference**:
A dashboard user’s choice of language for application UI. It does not translate store data or customer-facing documents.
_Avoid_: Shop language, system language

**Store Document Language**:
The future store-wide choice of language for customer-facing receipts and invoices. Until this preference exists, document content remains English.
_Avoid_: User language preference, storage language
