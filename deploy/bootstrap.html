Trust this store, then open the scanner

Your phone needs the store certificate once. It lets the browser use the camera securely without an internet connection.

  1. Download the store certificate

    Only install root.crt. Never accept or share a file named root.key.

    Download root.crt

  2. Verify it, then mark it as trusted

    On the desktop, the installer prints the expected Root CA SHA-256 fingerprint. Compare it with this certificate's details before enabling trust. If they differ, do not install it.

    Android instructions

    Open Settings → Security → More security settings → Install a certificate → CA certificate, then select root.crt. Names vary slightly by phone.

    iPhone and iPad instructions

    Install the downloaded profile, then open Settings → General → About → Certificate Trust Settings and enable full trust for the Stores4U certificate.

  3. Open Stores4U

    Allow camera access when prompted. Bookmark the address for later.

    Open {{APP_URL}}

Keep this certificate installed while using this store. If the desktop is reinstalled, restore its Caddy data backup so phones do not need a new certificate.
